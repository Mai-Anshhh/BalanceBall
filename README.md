# BalanceBall
A simple game where you have to balance a ball over a platform, making sure it does not fall!

This game has a highscore which adds 5 points for every 5 seconds you keep your ball on the platform.

# AI usage
I used Ai in debugging and figuring out the movement for the ball as it was not the normal charcter body 2D node, I had to use rigid body 2D to make it react with the platform, and needed help in figuring its script, beyond that, I used Ai at a few places for debugging only.
